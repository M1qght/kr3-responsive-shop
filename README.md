# MadShop — контрольная работа №3

Адаптивный многостраничный интернет-магазин компьютерной периферии. Основа проекта — [КР №1](https://github.com/M1qght/kr1-html-css-shop/tree/1f3a2e8597712a502958a4897223be5976b5bace).

## Как открыть проект

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны. Для просмотра через локальный сервер запустите `python -m http.server 8000` из папки проекта и откройте `http://localhost:8000/`.

- `index.html` — главная с популярными товарами и быстрым заказом.
- `catalog.html` — каталог с боковой панелью фильтров.
- `product.html` — карточка Forge K75, характеристики и комплектация.
- `order.html` — форма заявки.
- `contacts.html` — контакты, доставка и возврат.
- `css/style.css` — общие стили. `css/responsive.css` — адаптивная раскладка.
- `images/responsive/` — WebP-варианты фотографий товаров.
- `js/main.js` — быстрое оформление и валидация заявок в браузере.

## ПР №12. Адаптивная вёрстка

- Mobile First: одна колонка на узких экранах. С 640 px карточки переходят на две колонки, с 1024 px фильтры каталога и блоки на странице заявки выстраиваются рядом с основным содержимым. Шапка закрепляется с 768 px.
- Главное изображение использует `picture` и WebP с PNG на случай отсутствия поддержки. Карточки и страница товара используют `srcset` и `sizes`.
- Поля заявки располагаются в одну колонку до 768 px. Модальная форма прокручивается внутри окна на невысоком экране. Таблица характеристик при необходимости прокручивается внутри своего контейнера.

Проверены все пять страниц на ширинах 360, 430, 768, 1024 и 1440 px.

## ПР №13. Изображения, ARIA и Lighthouse

- Проверены `alt` у всех изображений. Для фотографий уточнены описания, у логотипов рядом с названием магазина оставлен пустой `alt`.
- Убраны дублирующие и неприменимые ARIA-атрибуты. Поля с ошибками теперь получают `aria-invalid="true"`. Для уведомления о заявке используется `role="status"`.
- Lighthouse 13.6.0, профиль Mobile, категория Accessibility. Каждая страница получила 100/100 после внесения изменений.
